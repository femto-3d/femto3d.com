GitHub Sync Settings

Your logs live in a real SQLite database file (data/workout-log.db) inside your own GitHub repository. Every save is committed to the repo and syncs across devices.

  1. Create a fine-grained personal access token at github.com/settings/personal-access-tokens
  2. Repository access: only this repo
  3. Permissions: Contents → Read and write
  4. Paste it below. It is stored only in this browser.
